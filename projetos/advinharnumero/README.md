# Jogo de Adivinhação em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema funciona como um jogo simples de adivinhação onde o usuário precisa tentar acertar um número secreto.

* A ideia principal foi praticar entrada de dados, operadores relacionais e estruturas condicionais dentro de um algoritmo simples.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e na criação de validações dentro da programação.

Durante esse projeto eu consegui entender melhor como funcionam comparações e validações dentro da programação.

No começo eu tive dificuldade para organizar a lógica de comparação entre o número digitado e o número secreto.

Depois de praticar mais, comecei a entender melhor como estruturas condicionais conseguem controlar diferentes resultados dentro do sistema.

Esse projeto também ajudou bastante no entendimento de entrada e saída de dados utilizando leia, escreva e escreval.

A parte das validações ficou mais clara para mim depois de testar diferentes palpites e analisar o comportamento do algoritmo.

Mesmo sendo um jogo simples, consegui perceber melhor como pequenas decisões lógicas conseguem criar interações dentro de um sistema.
