# Biblioteca Matemática em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema funciona como uma pequena biblioteca matemática capaz de realizar operações básicas entre dois números.

* A ideia principal foi praticar operadores matemáticos, variáveis e entrada de dados dentro de um algoritmo simples.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e na compreensão de cálculos matemáticos dentro da programação.

No começo eu tive dificuldade para organizar os cálculos corretamente e entender como utilizar operadores matemáticos em diferentes operações.

Depois de praticar mais, comecei a entender melhor como variáveis armazenam valores e como esses dados podem ser utilizados em cálculos dentro do algoritmo.

Esse projeto também ajudou bastante no entendimento de entrada e saída de dados utilizando leia, escreva e escreval.

A parte das operações matemáticas ficou mais clara para mim depois de testar diferentes números e analisar os resultados retornados pelo sistema.

Mesmo sendo um sistema simples, consegui perceber melhor como cálculos básicos funcionam dentro da programação.
