# Sistema de Mercado em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema simula uma compra simples de mercado verificando se o valor pago pelo cliente é suficiente para realizar a compra.

* A ideia principal foi praticar operadores matemáticos, operadores relacionais e estruturas condicionais dentro de um algoritmo simples.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e no entendimento de validações financeiras básicas.

* Cadastro do nome do produto
* Cadastro do preço do produto
* Entrada do valor pago
* Verificação de pagamento
* Cálculo automático do troco
* Validação de dinheiro insuficiente
* Exibição do resultado final
* Interação com usuário pelo terminal

Durante esse projeto eu consegui entender melhor como funcionam validações financeiras dentro da programação.

No começo eu tive dificuldade para organizar corretamente a lógica da comparação entre o valor pago e o preço do produto.

Depois de praticar mais, comecei a entender melhor como operadores relacionais conseguem validar diferentes situações dentro de um sistema.

Esse projeto também ajudou bastante no entendimento de cálculos matemáticos utilizando subtração para calcular o troco automaticamente.

A parte das condicionais ficou mais clara para mim depois de testar diferentes valores de pagamento e verificar como o sistema reagia em cada situação.

Mesmo sendo um sistema simples, consegui perceber melhor como pequenas validações podem criar regras importantes dentro de uma aplicação.
