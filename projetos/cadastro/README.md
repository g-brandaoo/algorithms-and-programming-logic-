# Sistema de Cadastro em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema permite cadastrar usuários, listar informações, editar dados e remover registros através de um menu interativo simples.

* A ideia principal foi praticar estruturas básicas da programação criando um sistema organizado e funcional.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e na manipulação de vetores.

Durante esse projeto eu consegui entender melhor como funciona um sistema de cadastro utilizando lógica de programação.

No começo eu tive dificuldade para organizar os vetores e controlar as posições dos usuários cadastrados. Depois de praticar mais, comecei a entender melhor como armazenar dados relacionados ao mesmo usuário sem perder informações.

Também consegui entender melhor como funcionam menus interativos e estruturas condicionais dentro de um sistema maior.

A parte de edição e remoção de usuários ajudou bastante no meu raciocínio lógico, principalmente para validar posições existentes dentro do vetor.

As estruturas de repetição ficaram mais claras para mim durante a listagem de usuários e na navegação do menu principal.

Depois de terminar o sistema, ficou mais fácil entender como vários conceitos básicos podem trabalhar juntos para criar um sistema funcional e organizado.
