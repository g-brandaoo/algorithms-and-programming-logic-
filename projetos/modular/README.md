# Sistema Modular em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema verifica se um número é divisível por outro utilizando a operação modular.

* A ideia principal foi praticar operadores matemáticos, estruturas condicionais e validação de resultados dentro de um algoritmo simples.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e no entendimento da operação MOD.

Durante esse projeto eu consegui entender melhor como funciona a operação MOD dentro da programação.

No começo eu tive dificuldade para entender como verificar se um número era divisível por outro utilizando resto da divisão.

Depois de praticar mais, comecei a entender melhor como operadores matemáticos e condicionais trabalham juntos para validar informações.

Esse projeto também ajudou bastante no entendimento de comparação de valores utilizando estruturas condicionais.

A parte da divisibilidade ficou mais clara para mim depois de testar diferentes números e analisar os resultados retornados pelo sistema.

Mesmo sendo um sistema simples, consegui perceber melhor como pequenas verificações matemáticas podem ser usadas dentro de algoritmos.
