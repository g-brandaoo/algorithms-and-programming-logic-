# Sistema de Login Infinito em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema realiza verificações de login utilizando usuário e senha através de um loop infinito.

* A ideia principal foi praticar estruturas de repetição, operadores lógicos e validação de dados dentro de um algoritmo simples.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e no entendimento de autenticação básica dentro da programação.

Durante esse projeto eu consegui entender melhor como funciona um sistema de autenticação utilizando lógica de programação.

No começo eu tive dificuldade para organizar a validação de usuário e senha utilizando múltiplas condições ao mesmo tempo.

Depois de praticar mais, comecei a entender melhor como operadores lógicos conseguem validar diferentes informações dentro de um sistema.

Esse projeto também ajudou bastante no entendimento de estruturas de repetição utilizando enquanto verdadeiro para manter o sistema funcionando continuamente.

A parte das condicionais ficou mais clara para mim depois de testar diferentes combinações de usuário e senha para verificar os resultados retornados pelo sistema.

Mesmo sendo um sistema simples, consegui perceber melhor como autenticação básica funciona dentro da programação.
