# Sistema Bancário em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema simula operações bancárias simples como depósito, saque e consulta de saldo através de um menu interativo.

* A ideia principal foi praticar estruturas de repetição, condicionais e menus utilizando um sistema mais próximo de aplicações reais.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e na criação de validações financeiras básicas.

Durante esse projeto eu consegui entender melhor como funciona a lógica de um sistema bancário simples dentro da programação.

No começo eu tive dificuldade para organizar o menu interativo e controlar corretamente as operações de depósito e saque sem perder o valor atualizado do saldo.

Depois de praticar mais, comecei a entender melhor como estruturas de repetição conseguem manter um sistema funcionando continuamente até o usuário decidir encerrar.

Esse projeto também ajudou bastante no entendimento de validações utilizando condicionais, principalmente para impedir saques maiores que o saldo disponível.

A parte do menu com escolha caso ficou mais clara para mim depois de testar diferentes operações e verificar como o sistema reagia a cada opção.

Mesmo sendo um sistema simples, consegui perceber melhor como diferentes blocos de lógica trabalham juntos para criar uma aplicação funcional.
