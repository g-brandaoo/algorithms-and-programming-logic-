# Contador Simples em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema realiza uma contagem regressiva utilizando estruturas de repetição.

* A ideia principal foi praticar loops, operadores matemáticos e controle de fluxo dentro de um algoritmo simples.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e no entendimento de estruturas de repetição.

* Entrada de número inteiro
* Contagem regressiva automática
* Exibição dos números na tela
* Atualização do valor a cada repetição
* Encerramento automático da contagem
* Interação com usuário pelo terminal

Durante esse projeto eu consegui entender melhor como funcionam estruturas de repetição dentro da programação.

No começo eu tive dificuldade para entender como o laço enquanto conseguia repetir ações automaticamente até atingir uma condição específica.

Depois de praticar mais, comecei a entender melhor como variáveis podem ser atualizadas dentro de loops para controlar o fluxo do sistema.

Esse projeto também ajudou bastante no entendimento de decremento e controle de contagem utilizando operadores matemáticos.

A parte da repetição ficou mais clara para mim depois de testar diferentes números e analisar como o sistema executava a contagem regressiva.

Mesmo sendo um sistema simples, consegui perceber melhor como estruturas de repetição funcionam dentro da lógica de programação.
