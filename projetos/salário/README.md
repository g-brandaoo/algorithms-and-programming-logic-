# Sistema de Cadastro de Funcionários e Salários em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

- Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

- O sistema permite cadastrar funcionários, armazenar salários, listar registros, editar informações e excluir funcionários através de um menu interativo.

- A ideia principal foi treinar manipulação de vetores, estruturas condicionais, repetição e organização de dados em memória.

- Esse projeto ajuda no desenvolvimento do raciocínio lógico e na criação de pequenos sistemas administrativos.

Durante esse projeto eu consegui entender melhor como funciona o gerenciamento de dados utilizando vetores dentro de um sistema simples.

A parte mais importante foi aprender a armazenar informações relacionadas em posições equivalentes dos vetores, mantendo os nomes e salários organizados corretamente.

Também consegui praticar bastante estruturas condicionais para validar posições existentes antes de editar ou excluir funcionários do sistema.

Outro aprendizado importante foi entender como reorganizar os vetores após remover um funcionário. Isso ajudou bastante no raciocínio lógico e no entendimento de como sistemas trabalham internamente com listas de dados.

As estruturas de repetição ajudaram no processo de listagem dos funcionários e na movimentação dos dados dentro dos vetores.

Além disso, consegui melhorar a organização do algoritmo utilizando menus e separando melhor cada funcionalidade do sistema.
