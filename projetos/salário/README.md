# Sistema de Salário em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

- Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

- O sistema permite cadastrar funcionários, calcular salários, aplicar descontos, calcular horas extras e gerenciar informações salariais através de um menu interativo.

- A ideia principal foi criar um sistema simples de gerenciamento salarial utilizando vários conceitos importantes para quem está começando na programação.

- Esse projeto ajudou no desenvolvimento do raciocínio lógico, na organização de algoritmos e no entendimento de como sistemas administrativos funcionam.

Durante esse projeto eu consegui entender melhor como organizar um sistema utilizando lógica de programação.

No começo eu tive dificuldade principalmente para entender como calcular salários e organizar os dados dos funcionários usando vetores e matrizes. Eu me confundia bastante com posições e também errava vários cálculos no início.

Depois de praticar mais, comecei a entender melhor como separar cada informação do funcionário em vetores diferentes e como usar matrizes para armazenar resultados do salário bruto, horas extras e salário líquido.

Também consegui aprender melhor a diferença entre procedimentos e funções. Antes eu fazia tudo diretamente no menu principal e o código ficava muito bagunçado. Depois que comecei a separar as funcionalidades, ficou muito mais fácil entender o sistema e corrigir erros.

Outra dificuldade foi fazer a lógica de remoção de funcionários sem perder os dados dos outros funcionários. Isso ajudou bastante no meu raciocínio lógico porque precisei entender como mover informações dentro dos vetores corretamente.

Esse projeto ajudou bastante no meu entendimento sobre:
- cálculos salariais
- operadores matemáticos
- estruturas condicionais
- laços de repetição
- organização de algoritmos

Depois de terminar o sistema, ficou mais fácil entender como dividir problemas grandes em partes menores e como organizar melhor um projeto de programação.

Além disso, consegui melhorar bastante a leitura do código usando comentários e nomes de variáveis mais organizados.

No futuro quero aprender:
- *Python e outras linguagens*
- *Cibersegurança*
- *Banco de dados*
- *Redes*
- *Linux*
- *Desenvolvimento backend*

Esse projeto foi importante porque mostrou na prática como vários conceitos básicos trabalham juntos dentro de um sistema real.
