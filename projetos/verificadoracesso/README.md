# Sistema de Verificador de Acesso em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

- Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

- O sistema permite cadastrar usuários, realizar login, validar senha, verificar níveis de acesso e bloquear tentativas inválidas através de um menu interativo.

- A ideia principal foi criar um projeto simples, mas que utilizasse vários conceitos importantes da programação para iniciantes.

- Esse projeto ajuda no desenvolvimento do raciocínio lógico e na organização de algoritmos.

Durante esse projeto eu consegui entender melhor como funciona um sistema de login e verificação de acesso utilizando lógica de programação.

No começo eu tive bastante dificuldade para organizar os vetores e a matriz, porque eu me confundia com as posições dos usuários e com os dados armazenados em cada coluna. Depois de praticar mais, comecei a entender melhor como armazenar informações relacionadas ao mesmo usuário sem perder os dados.

Também consegui entender melhor como funcionam funções e procedimentos dentro de um sistema maior. Antes eu fazia praticamente tudo direto no algoritmo principal, mas durante o projeto percebi que separar o código em partes organizadas deixa tudo mais fácil de entender e corrigir.

Outra parte que me deu trabalho foi a validação de login e senha. Tive que pensar bastante na lógica para bloquear usuários após várias tentativas inválidas sem quebrar o funcionamento do sistema.

As estruturas condicionais também ficaram mais claras para mim depois desse projeto, principalmente em situações onde o sistema precisava tomar decisões diferentes dependendo da senha, do login ou do nível de acesso do usuário.

A parte de repetição ajudou bastante no meu raciocínio lógico, principalmente para percorrer vetores, buscar usuários e listar informações na tela.

Depois de terminar o sistema, ficou muito mais fácil entender como pequenos blocos de lógica trabalham juntos para formar um sistema completo.
