# Sistema Verificador de Acesso em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema permite cadastrar usuários, realizar login, listar contas e excluir usuários através de um menu interativo.

* A ideia principal foi criar um sistema de autenticação simples utilizando vetores, repetição e validação de dados.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e no entendimento de controle de acesso dentro da programação.

Durante esse projeto eu consegui entender melhor como funciona um sistema de autenticação utilizando lógica de programação.

No começo eu tive dificuldade para organizar os vetores de login e senha sem misturar os dados dos usuários cadastrados.

Depois de praticar mais, comecei a entender melhor como estruturas de repetição conseguem percorrer vetores para buscar informações específicas dentro do sistema.

Esse projeto também ajudou bastante no entendimento de validações utilizando operadores lógicos para comparar login e senha ao mesmo tempo.

A parte da exclusão de usuários foi uma das mais difíceis, porque precisei mover os dados dos vetores para evitar espaços vazios após remover um usuário.

As estruturas condicionais também ficaram mais claras para mim depois de testar diferentes situações de login válido e inválido.

Mesmo sendo um sistema simples, consegui perceber melhor como sistemas reais de autenticação utilizam validações, armazenamento de dados e controle de acesso.
