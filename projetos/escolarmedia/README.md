# Sistema de Média Escolar em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema permite cadastrar alunos, calcular médias, editar notas, excluir registros e listar informações através de um menu interativo.

* A ideia principal foi criar um sistema mais completo utilizando vetores, estruturas de repetição e validações dentro de um único algoritmo.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e na organização de dados utilizando vetores.

Durante esse projeto eu consegui entender melhor como funciona a organização de dados utilizando vetores dentro da programação.

No começo eu tive bastante dificuldade para controlar as posições dos alunos e atualizar corretamente as notas e médias sem perder informações.

Depois de praticar mais, comecei a entender melhor como estruturas de repetição conseguem percorrer vetores para listar, editar e excluir dados dentro de um sistema.

Esse projeto também ajudou bastante no entendimento de menus interativos utilizando escolha caso para organizar diferentes funcionalidades.

A parte da exclusão de alunos foi uma das mais difíceis, porque precisei entender como mover os dados dos vetores para não deixar espaços vazios dentro do sistema.

As validações também ficaram mais claras para mim depois de testar posições inválidas e verificar como o sistema reagia a diferentes situações.

Mesmo sendo um sistema simples, consegui perceber melhor como vários conceitos básicos trabalham juntos para formar uma aplicação mais organizada.
