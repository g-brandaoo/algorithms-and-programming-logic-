# Jogo RPG com Mercado Simples em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema simula uma batalha simples entre um herói e um monstro com um pequeno sistema de mercado utilizando pontos.

* A ideia principal foi juntar combate, repetição, condicionais e sistema de compra dentro de um único algoritmo.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e no entendimento de sistemas interativos simples.

Durante esse projeto eu consegui entender melhor como vários sistemas pequenos podem funcionar juntos dentro de um único algoritmo.

No começo eu tive dificuldade para organizar corretamente a lógica da batalha, principalmente no controle da vida do herói e do monstro durante os ataques.

Depois de praticar mais, comecei a entender melhor como estruturas de repetição conseguem manter o jogo funcionando continuamente até atingir uma condição final.

Esse projeto também ajudou bastante no entendimento de condicionais, porque o sistema precisava verificar vitória, derrota e compra de itens ao mesmo tempo.

A parte do mercado foi uma das mais interessantes, porque consegui entender melhor como criar sistemas de recompensa utilizando pontos dentro de um jogo.

Também comecei a perceber como operadores matemáticos podem ser usados para criar mecânicas simples de combate e evolução dentro de sistemas interativos.

Mesmo sendo um projeto simples, consegui enxergar melhor como jogos funcionam internamente utilizando apenas lógica de programação.
