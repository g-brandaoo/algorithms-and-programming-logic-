# Sistema de Aprovação Escolar em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema calcula a média final de um aluno e verifica sua aprovação com base nas notas e na frequência escolar.

* A ideia principal foi praticar operadores matemáticos, operadores lógicos e estruturas condicionais dentro de um algoritmo simples.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e no entendimento de validações utilizando múltiplas condições.

---

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Funcionalidades" alt="Typing SVG" /></a>

* Cadastro do nome do aluno
* Entrada de três notas
* Entrada da frequência escolar
* Cálculo automático da média
* Verificação de aprovação
* Validação utilizando média e frequência
* Exibição do resultado final
* Interação com usuário pelo terminal

Durante esse projeto eu consegui entender melhor como funcionam validações utilizando múltiplas condições dentro da programação.

No começo eu tive dificuldade para organizar a lógica da aprovação escolar, principalmente para validar média e frequência ao mesmo tempo.

Depois de praticar mais, comecei a entender melhor como operadores lógicos conseguem conectar diferentes condições dentro de um sistema.

Esse projeto também ajudou bastante no entendimento de cálculos matemáticos utilizando soma e divisão para gerar a média final do aluno.

A parte das condicionais ficou mais clara para mim depois de testar diferentes valores de média e frequência para verificar os resultados do sistema.

Mesmo sendo um sistema simples, consegui perceber melhor como pequenas validações podem ser usadas para criar regras dentro de um algoritmo.
