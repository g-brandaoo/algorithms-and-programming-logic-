# Sistema de Média Escolar em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

- Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

- O sistema permite cadastrar alunos, inserir notas, calcular médias e informar automaticamente a situação do aluno.

- A ideia principal foi criar um sistema simples, mas que utilizasse vários conceitos importantes da programação para iniciantes.

- Esse projeto ajuda bastante no desenvolvimento do raciocínio lógico e na organização de algoritmos.

Durante esse projeto eu consegui entender melhor como organizar um sistema utilizando lógica de programação.

No começo eu tive dificuldade principalmente para trabalhar com vetores e matrizes, porque eu confundia bastante as posições e os índices. Depois de praticar mais, comecei a entender melhor como armazenar e acessar as informações corretamente.

Também consegui aprender melhor como dividir um sistema em procedimentos e funções. Antes eu fazia tudo diretamente no algoritmo principal, mas conforme o projeto foi crescendo percebi como organizar o código deixa tudo mais fácil de entender e manter.

Outra parte que me deu trabalho foi a lógica da remoção de alunos, porque precisei mover os dados dentro dos vetores e da matriz sem perder informações.

Esse projeto ajudou bastante no meu raciocínio lógico, principalmente na parte de estruturas condicionais e repetição. Depois de terminar o sistema, ficou mais fácil entender como resolver problemas maiores separando em pequenas etapas.

Além disso, consegui melhorar:
- organização do código
- reutilização de funções
- criação de menus
- cálculo de média
- uso de vetores e matrizes
- lógica de busca e edição

No futuro quero aprender:
- *Python e outras línguas*
- *Cibersegurança*
- *Segurança da nuvem*
- *Redes*
- *Computadores*
- *Me adaptar a um sistema operacional linux*

Esse projeto foi importante porque mostrou na prática como vários conceitos básicos trabalham juntos dentro de um sistema real.
