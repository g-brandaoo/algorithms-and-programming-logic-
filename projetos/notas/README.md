# Sistema de Notas de Dinheiro em Portugol

<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.herokuapp.com?font=Montserrat&duration=2000&pause=1000&color=89CFF0&repeat=false&width=435&lines=Objetivo+do+projeto" alt="Typing SVG" /></a>

* Este projeto foi desenvolvido para praticar lógica de programação utilizando Portugol no Visualg.

* O sistema calcula o valor total de dinheiro com base na quantidade de notas informadas pelo usuário.

* A ideia principal foi praticar operações matemáticas, entrada de dados e manipulação de variáveis dentro de um algoritmo simples.

* Esse projeto ajudou no desenvolvimento do raciocínio lógico e na organização de cálculos dentro da programação.

* Entrada da quantidade de notas
* Cálculo automático do valor total
* Soma de diferentes valores monetários
* Exibição do resultado final
* Interação com usuário pelo terminal

Durante esse projeto eu consegui entender melhor como funcionam operações matemáticas dentro da programação.

No começo eu tive dificuldade para organizar os cálculos corretamente e lembrar de multiplicar cada quantidade pelo valor correspondente da nota.

Depois de praticar mais, comecei a entender melhor como utilizar variáveis para armazenar valores diferentes e combinar todos os resultados em um único cálculo.

Esse projeto também ajudou bastante no entendimento de entrada e saída de dados utilizando leia, escreva e escreval.

A parte dos cálculos matemáticos ficou mais clara para mim depois de testar diferentes quantidades de notas e verificar o resultado final.

Mesmo sendo um sistema simples, consegui perceber melhor como pequenos cálculos podem ser organizados dentro de um algoritmo.
